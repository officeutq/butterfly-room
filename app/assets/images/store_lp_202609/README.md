# 店舗向けLP 202609 画像メモ

このディレクトリのWebPは、店舗向けLP 202609で使用する画像である。画像を差し替える際は、同じファイル名で差し替えるか、Viewの参照先を変更する。

## `hero_cast_customer_connection.webp`

- 使用箇所: ファーストビュー右側
- 必要な画像: 夜のお店らしい店内で、キャストがスマートフォンを使って明るくライブ配信している場面
- 伝えたいこと: 来店できないお客様ともオンラインで自然につながれること
- 推奨構図: キャストを中心にした縦位置。スマートフォンと店内の雰囲気が分かり、文字を重ねる下部に余白があること
- 推奨比率: 4:5
- 注意: 実在店舗や利用実績と誤認される素材、権利未確認の人物写真は使用しない

## `use_case_before_open.webp`

- 使用箇所: 活用シーン「営業前のちょっとした時間に」
- 必要な画像: 営業開始前の店内で、準備を終えたキャストがスマートフォンから短時間配信している場面
- 伝えたいこと: 営業前の短い時間でも利用できること
- 推奨構図: 横位置。キャスト、スマートフォン、開店前の店内が分かること
- 推奨比率: 4:3

## `use_case_day_off.webp`

- 使用箇所: 活用シーン「店休日に」
- 必要な画像: 店休日に、落ち着いた場所からお客様へライブ配信するキャストの場面
- 伝えたいこと: 店舗を開けていない日にもお客様との接点をつくれること
- 推奨構図: 横位置。通常営業中ではない落ち着いた雰囲気と配信中のスマートフォンが分かること
- 推奨比率: 4:3

## `use_case_remote_customer.webp`

- 使用箇所: 活用シーン「来店が難しいお客様に」
- 必要な画像: 遠方や仕事の都合で来店できないお客様が、スマートフォンでキャストの配信を見ている場面
- 伝えたいこと: 距離や予定にかかわらずオンラインで会えること
- 推奨構図: 横位置。お客様の手元または生活空間と、スマートフォン上の配信が分かること
- 推奨比率: 4:3

## `use_case_sns_connection.webp`

- 使用箇所: 活用シーン「SNSでつながっているお客様に」
- 必要な画像: SNSの投稿またはメッセージからライブ配信ページへ案内する流れが分かる写真・画面イメージ
- 伝えたいこと: SNSでの接点を実際に話せる配信や来店へつなげられること
- 推奨構図: 横位置。SNSとライブ配信の2画面、または案内するキャストと受け取るお客様の関係が分かること
- 推奨比率: 4:3
- 注意: 実在サービスのロゴや個人情報を写り込ませない
