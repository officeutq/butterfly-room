# ブース・店舗選択の共通操作

2026-09-16にmainへマージした選択改修の操作手順です。ステージングへの反映・確認状況は[環境別記録](../ops/current_selection_staging_verification.md)を参照してください。本番には未反映です。

## 選択できる条件

| 状態 | 選択の扱い |
| --- | --- |
| 利用できる候補がない | 未選択となり、必要な操作へ進むと候補がない旨を案内します。選択モーダルは出ません |
| 候補が1件 | 自動選択されます。手動変更のリンク・モーダルは出ません。店舗変更時の例外は下記参照 |
| 本人が配信中・離席中 | 本人が配信しているブース・店舗に固定されます。変更するには先に配信を終了します |
| 候補が複数で本人が未配信 | 有効な選択があれば維持します。未選択なら、ブース情報・配信など必要な操作へ進む時に選びます |

キャストのブース候補は未閉鎖の担当ブースです。店舗管理者は管理する全店舗、システム管理者は全店舗のブースを選べます。管理者の候補には閉鎖済みも含まれ、現役1件＋閉鎖済み1件なら2件として扱います。他の人が配信中のブースも情報確認のため選べますが、配信準備・開始はできません。

本人の配信終了後は同じブースの選択を維持します。複数候補がある場合は、再び手動で変更できます。別タブ・別端末で表示が古い場合は再読み込みしてください。古いリンクが残っていても、配信中・離席中の切替は受け付けません。

## ヘッダーから変更する

1. ヘッダー右側の自分の名前・アイコンを押し、メニューを開きます。
2. ブース名、または店舗名を押します。未選択なら「未選択」と表示されます。固定中は名前だけの表示となり、押せません。
3. モーダル内で切替先を選びます。ブースを選ぶと所属店舗も切り替わります。「閉じる」なら選択は変わりません。
4. 編集中の内容が未保存の場合は破棄確認を表示します。キャンセルすると元の入力を維持します。変更を確定した後は、対応する画面を開き直します。

店舗を手動変更できるのは店舗管理者・システム管理者です。店舗は「店舗を選択」カードからも同じモーダルを開けます。選択済みブースを通常の操作で変更する入口はヘッダーです。旧管理画面に残る切替ボタンの整理は後続対応です。

## 切替後の画面

| 開いていた画面 | 切替後 |
| --- | --- |
| ブース情報・編集・配信履歴 | 切替先の同じ種類の画面。閉鎖済みを編集しようとした場合は情報画面へ |
| 店舗に依存する編集・管理画面 | 新しい店舗の対応画面。古いフォームを別タブに残して保存しても、新しい対象へ内容を転用しません |
| 配信準備 | 切替先の配信準備。映像・音声の準備も新しい対象で行います |
| 準備から、他者配信中・離席中／閉鎖済み／非公開店舗のブースへ | 切替先の情報画面で、準備できない理由を案内します |
| 公開店舗・ブース・プロフィール詳細、個別の配信結果 | 見ていた対象を維持します。ヘッダーの選択とは別です |

準備の切替だけで、元の未開始の準備や保存済みタイトルを終了・削除しません。開始途中の場合は、その開始の取消を確認してから切り替えます。取消や切替先の状態確認に失敗した場合は、切替を完了させず元の画面を維持します。

## 店舗を変更したとき

同じ店舗を選び直すだけではブースを解除しません。別店舗へ変更した場合はブースをいったん未設定にします。利用できる全ブースが1件だけで、そのブースが変更先の店舗にある場合は自動選択します。複数候補から勝手に1件を選ぶことはありません。

例：店舗A・Bがあり、ブースはA店の1件だけの場合。

| 操作 | 結果 |
| --- | --- |
| A店→B店 | B店へ切替。ブースは未設定 |
| B店を表示・再読み込み | B店とブース未設定を維持 |
| B店でブース情報・配信へ進む | 選択モーダルを出さず、A店と唯一のブースへ自動設定 |
| B店→A店 | A店と唯一のブースを自動設定 |

本人が配信中・離席中の場合は、上記より本人の配信ブース・店舗への固定を優先します。

キャスト招待を承認した場合は例外として、新しいブースと店舗に切り替えます。完了通知に店舗名・ブース名を表示し、初回のブース編集へ進みます。招待画面の表示や承認失敗だけでは切り替えません。本人が配信中・離席中なら、終了後に承認してください。

## 配信・公開状態との関係

ホームで選択外のブースカードを開くと、視聴画面へ進み、選択は変わりません。選択中の担当ブースではキャストは配信準備へ、管理者は「視聴／配信」の選択へ進みます。

非公開店舗は情報確認・管理の対象として選べますが、配信準備・開始はできません。準備画面を開いた後に店舗が非公開になった場合も開始できません。配信中・離席中・開始処理中のブースがある店舗は、通常の店舗編集から非公開にできません。配信終了または開始取消後に操作してください。

管理者が閉鎖済みを選択しても配信準備・開始・編集はできません。閉鎖済み情報画面を「履歴のみ」に整理する変更は後続対応です。現在残っている共有ボタンや、まだ表示されない履歴ボタンを、今回の選択変更で対応済みとは扱いません。

## 困ったとき

- **候補がない：** 所属・管理権限・ブースの閉鎖状況を店舗管理者へ確認してください。
- **別ブースのURLを開くと選択を求められる：** ヘッダーから対象を選んでください。URLを開くだけでは選択は変わりません。
- **「配信状態を確認できません」：** 状態を確かめられていないため切替・準備を保留しています。再確認し、繰り返す場合は管理者へ連絡してください。空いていることを示すメッセージではありません。
- **通信や保存に失敗した：** 元の入力と選択を確認して再試行してください。別タブで対象を変えた古いフォームは、そのまま保存せず対象を確認し直してください。
- **配信終了後もヘッダーが押せない：** 再読み込みしてください。候補が1件なら終了後も固定表示のままです。
