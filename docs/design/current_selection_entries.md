# 選択の既存入口と共通処理の対応（#1274）

2026-09-16。#1256の調査時点の41項目は変更せず、現在の実装への対応を記録する。

## 共通の接続箇所

- [CurrentSelection](../../app/controllers/concerns/current_selection.rb)でログインsessionを読み書きし、同じ結果をヘッダーと本文へ渡す。拒否結果は保存しない。
- [CurrentSelectionService](../../app/services/current_selection_service.rb)が所属・候補・本人配信をDBで再判定する。選択用のIVS通信は追加しない。
- 戻り先は許可した画面種別から新しい対象のURLへ組み立てる。公開詳細と特定リザルトは元の対象を維持する。
- ドリンク・口座・ブース作成・店舗責任者代行登録・管理者招待の店舗指定がないフォームにはselection_store_idを保持する。欠落は再読込を案内し、不正は拒否、不一致は409。URL/レコードに対象IDがある更新は、その対象の認可後に照合する。
- 招待の共有済み/取消は発行済み招待IDに対する処理であり、選択変更で別招待へ読み替えない。配信終了・取消も元の配信ID/Y/世代を維持する。
- 店舗初回設定のpending店舗IDと招待初回編集のブースIDは、現在選択を業務対象に代替しない。新規登録の基本導線を保持する。
- 問い合わせの店舗文脈補助、公開リストの絞り込みは管理選択を保存しない。認証セッション自体のログアウト/破棄も通常の手動切替と区別する。

## 確認方法

- current_selection_entry_test：D01、対象不一致、古いHTML/JSON/Turboフォーム、不正要求、管理者の閉鎖済み、本人固定、候補GET、先読み、公開詳細/リザルト。
- cast/booth_navigation_test：キャスト・店舗管理者・システム管理者の情報/編集/履歴と閉鎖済み、未選択、有効選択保持。
- cast_invitation_flow_test / cast_invitation_broadcast_guard_test：成功通知、初回Bの固定、通常/SMSログイン復帰、配信中拒否、失敗時の維持。
- admin_store_selection_return_test / current_consistency_admin_test：同時保存、D01、同一店舗、無効選択、戻り先。
- publisher_preparation_test / publisher_full_flow_test：共通選択接続後もX準備/Y配信・再接続・終了を維持。外部IVSは模擬応答。
- 店舗登録・代行登録・ドリンク・口座・ブース作成の既存テストを更新し、フォームの元の対象IDと業務処理を確認する。

実端末の映像・音声、ステージング・本番への適用はこのローカル確認に含めない。環境横断の受入確認は#1277で区別して記録する。
